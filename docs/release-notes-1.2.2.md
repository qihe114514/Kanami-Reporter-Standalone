# 香奈美x黑潮爆破 · 手机版 v1.2.2

手机端首次公开发布。

## 本版重点

**应用内更新**

- 启动时自动检查新版本；发现有新版，「开始识别」会直接变成「更新到 vX.Y.Z」。
- 点开是一个液态玻璃弹窗，两个选择：**前往发布页**（浏览器打开，自己下载）或
  **下载并安装**（应用内直接下载，完成后拉起系统安装器）。
- 下载**不直连 GitHub**：先试直连，不通就自动改走加速通道，依次尝试多个镜像，
  国内网络环境下也能下动。
- 会**先申请「安装未知应用」权限再开始下载**，而不是等下载完才发现没权限。
- 手机版与电脑版共用同一个仓库；仓库里的手机版发布标签带 `mobile`，两者互不干扰。

**修好了「识别一会儿就没反应」**

之前版本运行几帧之后采集会彻底停下，表现为帧数停在 1、2、4 这种零散的数字上不再增长，
只有旋转屏幕才会再蹦出几帧。这个问题的根源已经找到并修复，现在可以稳定持续采集。

**界面重做**

- 运行页重排：识别状态、回合/阵营/比分、开始/停止都收进同一张主卡，打开就能看见主操作。
- 必须权限与模板匹配值改成可展开的卡片，权限齐全时只占一行。
- 内容区可以一路滚到屏幕最顶端和最底端，上下边缘是渐进模糊而不是硬切。
- 页面切换、卡片展开都有过渡动画。

**新增「个性化」设置**

可以调整界面玻璃的反射强度和模糊强度，纯观感，不影响识别。

**应用图标**

换成了与电脑版一致的香奈美表情包图标。

**其它**

- 「关于」页加入版本号、官网链接、GitHub 链接与检查更新。
- 悬浮窗不再能被拖出屏幕外。
- 去掉了「画面不动」这类误报——游戏卡住、加载中、停在桌面都是正常情况。

## 安装

下载 `KanamiReporter-1.2.2-qihe-release.apk` 安装即可。

如果之前装过 debug 版或其它签名的包，需要先卸载再装。
