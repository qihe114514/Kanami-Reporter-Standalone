# 香奈美x黑潮爆破 · 手机版 v1.2.4

## 本版重点

**适配更多分辨率的手机**

之前这一版只在你录第一份素材的那台手机上验证过（2772×1280，19.5:9）。换到别的手机
（比如 2376×1080，22:9）上，会出现一批"明明画面一模一样却认不出来"的情况：

- **购买阶段的「购买阶段」横幅**认不出 → 不播开局语音，回合数也不会增加；
- **「回合获胜 / 回合战败」横幅**认不出 → 不播回合结算语音；
- **选人画面的「VS」大字**认不出 → 新对局开始时不会重置回合数；
- **结算页的「胜利」大字**认不出 → 不播对局结算语音；
- **阵营（攻方 / 守方）判不出来** → 一直按攻方播报，「攻守互换」永远不触发。

（计时数字、炸弹面板、比分读数这几个本来还能用，所以看起来像"大部分正常，偶尔失灵"。）

原因不在模板，在**缩放**：识别前要把画面缩放到统一的坐标系再比对，之前用的是"按屏幕宽度
等比缩放"。这个做法把画面尺寸和屏幕的宽高比绑在了一起——游戏界面其实是按**屏幕高度**等比
排布的，所以换一个宽高比的屏幕，界面对不上，误差虽然只有一两个像素，但比对要求非常严，
宽一点的文字横幅就整体对不上了。

现在改成**按屏幕高度等比缩放、水平居中**。任何全面屏比例都通用，而且在你原来那台手机上
的识别结果和以前完全一样（模板一个都没动）。

**阵营（攻方 / 守方）更稳了**

攻守方是靠购买横幅下面那行小字认的，这行字背后是半透明底板，会透出后面的场景，所以分数
本来就飘。以前用的是"必须够高才认"的写法，场景一暗就认不到。现在改成两边比高低，只要
"攻方"明显比"守方"像就判攻方，反之亦然。你这次录的 16 分钟里，整场 8 个购买阶段阵营
全部判对（上半场守方，第 7 回合起换成攻方），没有一次误判。

**结算页「胜利」按机型做了两套**

这个大字在两台手机上整体差 15 像素，属于界面本身的差异，不是缩放问题。按"一个状态可以挂
多套模板、取最像的那个"的机制补了一套，两台手机现在都能认出来。

## 已知限制

- 五杀胜利 / 全员存活胜利 / 最后一人胜利 / 对局失败 / 对局平局：这几类结算画面**还没有模板**
  （一直如此，与分辨率无关），对应的专属语音不会播。需要相应画面的录屏后补。
- 更极端比例（21:9、16:9 平板）理论上同理可用，但**没有实机录屏验证过**。换了新手机
  先录一局看「关于」页的模板匹配值，异常的话把录屏发我。

## 安装

下载 `KanamiReporter-1.2.4-qihe-release.apk` 安装即可。

如果之前装过 debug 版或其它签名的包，需要先卸载再装。
