# 香奈美x黑潮爆破 · 手机版

> 本文是官网「手机端」页面用的文稿，可直接取用或改写。内容只讲怎么用，不含任何实现细节。

---

## 一句话介绍

把香奈美的声音带进《三角洲行动》手游——对局开始、炸弹安放、攻守互换、比分变化，她会自动开口。

---

## 它能做什么

- **自动播报**：进入对局、回合开始、炸弹安装、攻守互换、比分领先或落后、对局胜负……香奈美会在恰当的时机说恰当的话。
- **实时悬浮窗**：在游戏画面上显示当前阶段、回合数、攻守方、估算剩余时间和比分，不用切出去看。
- **比分读取**：直接从画面上读取双方比分；万一读数困难，会退回到按回合累计的估算值，界面不会空着。

## 三步开始使用

### 第一步：打开应用，把权限开齐

首次打开会列出四项必须的权限，逐项点过去开好就行：

| 权限 | 用来做什么 |
| --- | --- |
| 悬浮窗 | 在游戏画面上显示实时状态 |
| 后台驻留 | 让识别在游戏期间不被系统清理（被清理后需要重新授权录屏） |
| 无障碍 | 只用来判断当前在哪个应用、提升进程存活率，**不读取任何画面内容** |
| 通知 | 识别运行时需要在通知栏显示一条常驻通知 |

悬浮窗权限没开的话，识别仍然能用，只是游戏里看不到状态显示。

### 第二步：点「开始识别」

回到「运行」页，点 **开始识别**，系统会弹出录屏授权，选择 **整个屏幕** 并确认。

> 这是安卓系统的要求：任何要读取屏幕内容的应用都必须先获得你的明确授权，并且每次启动都会重新询问。本应用只读取画面来判断对局阶段，不会上传、不会保存画面。

### 第三步：切回游戏

授权完成后直接切回游戏开始对局。香奈美会随对局阶段自动播报，悬浮窗会显示当前状态。

**不需要在游戏里做任何额外操作。**

---

## 关于「竖屏」这件事

在应用里看到「采集运行中 · 切回游戏后自动识别」是正常的。

识别针对的是游戏的横屏画面，而你此时还在应用的竖屏界面里。切回游戏后横过来，它会自动开始，**不需要重新授权、也不需要重新点开始识别**。

---

## 悬浮窗

- 识别开始后自动出现，可以**拖动**到你顺手的位置，位置会被记住。
- **点一下**可以在收起（小胶囊）和展开（状态面板）之间切换。
- 在小胶囊上，颜色代表状态：绿色识别中、黄色需要注意、灰色未运行。
- 设置里可以整体关掉它。

---

## 设置页里有什么

- **匹配阈值**：识别灵敏度，已按实机验证调好，没有特殊需要保持默认即可。
- **游戏内悬浮窗**：开关悬浮窗显示。
- **启动时自动检查更新**：每次打开应用时检查一次有没有新版本。
- **个性化**：调整界面玻璃的反射强度和模糊强度，纯粹是观感，随便调。
- **必须权限**：权限清单，缺失时会自动展开并给出跳转入口。
- **关于**：版本号、官网与 GitHub 链接、检查更新。

## 常见问题

**识别没有反应？**

确认三条：权限是否开齐（尤其是悬浮窗和后台驻留）、是否已经点过「开始识别」并允许了录屏、手机是否处在**横屏的游戏画面**上（在应用内竖屏状态不做匹配）。

**它会修改游戏或干预游戏吗？**

不会。本应用只读取屏幕画面来判断当前处于对局的哪个阶段，然后播放本地的语音文件。它不修改游戏、不注入进程、不做任何自动化操作，也不会替你点任何按钮。

**为什么每次都要重新授权录屏？**

这是安卓系统的机制，不是本应用的设置。系统授权是一次性的，应用被系统回收后需要重新授权——把「后台驻留」权限开好可以显著减少这种情况。

**换了手机还能用吗？**

可以，但识别是依据画面裁剪出来的特征来做的，换分辨率或屏幕比例的机型可能出现识别不准。遇到这种情况可以在关于页反馈。

**语音能关掉吗？**

目前语音与识别状态绑定，识别停止就不会再播报。
