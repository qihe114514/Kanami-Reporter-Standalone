香奈美 x 黑潮爆破 —— 采集方式自检工具（KanamiCaptureDiag 1.0.6）
============================================================

这个工具用来查清楚"为什么采集不到游戏画面"。它不用安装，双击运行即可，
只读屏幕画面，不联网、不上传、不改动任何东西。


怎么用
------

1. 把游戏打开，切到实际对局画面（不要在最小化或后台的状态下测）。
2. 双击 KanamiCaptureDiag.exe。
3. 程序会列出可采集的目标（显示器和所有窗口），输入游戏窗口前面的编号，
   直接回车则自动选中三角洲行动的窗口。
4. 等它跑完（大约半分钟到一分钟），它会依次尝试这些采集方式：

   - Windows 图形捕获（窗口，默认显卡）—— 播报员程序当前用的方式
   - Windows 图形捕获（窗口，适配器 #N）—— 多显卡机器上换另一块显卡
   - Windows 图形捕获（窗口，HDR 浮点像素格式）—— 显示器开了 HDR 的情况
   - Windows 图形捕获（窗口所在显示器）—— 播报员程序黑屏后自动回退的方式
   - GDI 桌面 BitBlt / 窗口 DC BitBlt / PrintWindow —— 完全不依赖系统采集接口的老办法

5. 结束时程序会把日志和每个方式的截图打包成一个 zip，放在 exe 旁边，
   最后一行会打印它的完整路径。把这个 zip 发回来即可。

   也可以在命令行里指定目标，例如：
       KanamiCaptureDiag.exe --target 三角洲 --seconds 3


zip 里有什么
------------

- capture-diag.log
    系统版本与内部版本号、显卡与驱动版本、显示器分辨率与刷新率、每个窗口的
    句柄/进程/类名/是否最小化/防截屏标记，以及上面每一种采集方式的结果
    （首帧耗时、帧数、平均亮度、非黑像素比例、两帧差异）和结论。
- snapshots\snapshot-*.png
    每种采集方式各存一张画面对照。哪一张里是游戏，哪一种方式就能用。
    检查这几张图是判断"到底哪种方式能拿到画面"最直接的办法。


结果怎么看
----------

- 有效画面：能拿到画面，而且画面在变化 —— 这种方式可用。
- 有画面但无变化：画面不黑，但测试期间内容没变过。可能是画面本来就是静止的
  （菜单、加载、观战），也可能是游戏窗口在后台（被别的窗口挡住时系统不会
  继续更新它），少数情况是拿到了一张冻结的旧图。
- 全黑：画面被系统或游戏挡住了（防截屏标记为 WDA_MONITOR /
  WDA_EXCLUDEFROMCAPTURE 时属于预期行为）。
- 失败 / 无帧：这种采集方式在这个目标上直接不工作。如果备注里写着
  「像素读取卡住：帧回调在读第 N 帧的像素时没有返回」，说明系统已经送来画面，
  但这条路读不出来 —— 播报员程序 1.0.7 起遇到这种情况会自动改用 GDI 抓屏。


几点说明
--------

- 工具会把屏幕画面存成 PNG，用于人工确认，请自行注意截图内容的隐私。
- 日志里会记录窗口标题和进程路径，同样请注意隐私后再外发。
- 若提示"窗口已最小化"，请先把游戏切回可见状态再测。
